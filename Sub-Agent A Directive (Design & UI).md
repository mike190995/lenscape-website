# **Sub-Agent A Directive: Visual Design & Elegance**

## **Objective**

Piggyback off the existing Motion Magic Cam landing page framework, elevating it to an elegant, high-energy design language that represents The Lenscape Company Ltd.

## **Brand Guidelines & Theme**

* **Vibe:** Premium, modern, authoritative, and creative.  
* **Color Palette:**  
  * Primary Backgrounds: Pitch Black (\#000000) and Crisp White (\#FFFFFF) for high contrast.  
  * Primary Accent: Lenscape Yellow (referencing the vibrant yellow from the agency deck). Used sparingly but boldly for CTAs, highlights, and interactive hover states.  
* **Typography:**  
  * Headings: Bold, sharp geometric sans-serif (e.g., Montserrat, Syne, or similar).  
  * Body: Clean, highly legible sans-serif (e.g., Inter, Roboto).  
* **Shape Language:** Sharp, hard edges (0px border-radius) to mimic the structural cuts in the "LENSCAPE" logo.

## **Key Deliverables**

1. **Global CSS/Theme Config:** Generate the root variables or Tailwind config mapping out the colors, fonts, and sharp-edge utilities.  
2. **Animation Spec:** Define the CSS parameters for a high-energy hero video overlay and smooth, elegant scroll-reveal animations for the booth features (no bouncy animations; keep them sleek and fast).  
3. **UI Kit Mockup:** Provide styling rules for the booking popup modal to ensure it feels like a premium gateway rather than a standard web form.
