# **Lenscape Website & Booking Engine \- Master Plan**

**Framework:** Antigravity 2.0

**Project Name:** Lenscape Digital Upgrade

## **Agent Structure Overview**

The project is orchestrated by the **Director Agent (Master)**, which delegates tasks to three specialized **Sub-Agents**.

### **1\. Director Agent (Master)**

* **Role:** Project Manager & Orchestrator.  
* **Responsibility:** Ensures all Sub-Agents adhere to the "Lenscape" brand guidelines (elegant, high-contrast, black/white/yellow palette, sharp geometry). Merges the outputs of the Design, Frontend, and Backend agents into a cohesive deployment.

### **2\. Sub-Agent A: Design & UI Architect**

* **Role:** Visual Elegance & Animation Lead.  
* **Responsibility:** Transforms the existing Motion Magic Cam framework into an elegant, high-end agency experience. Defines global CSS/Tailwind variables, typography (bold geometric headers, clean sans-serif body), and scroll-triggered micro-animations.

### **3\. Sub-Agent B: Frontend Component Builder**

* **Role:** React/UI Developer.  
* **Responsibility:** Builds the high-energy hero video section, the interactive photo/video booth showcase, and the popup Booking Modal UI based on the specific form field requirements.

### **4\. Sub-Agent C: Backend & Data Integrator**

* **Role:** Booking Logic & Spreadsheet Sync.  
* **Responsibility:** Handles the semi-automated booking loop, form validation (enforcing the 2-hour minimum), pricing logic (custom arm paths), and the two-way webhook communication with the master approval spreadsheet.
